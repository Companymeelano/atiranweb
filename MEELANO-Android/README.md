# Meelano Android Direct SQL

این پروژه نسخه **اندروید واقعی و قابل نصب** برای Meelano است که برای تست شخصی با **اتصال مستقیم به SQL Server** آماده شده است.

## ویژگی‌های نسخه 3.20.0-direct-sql-stable-refresh-ux

### تغییرات مهم 3.20.0


- حذف میانبر اضافه «فرماندهی» از ابزارهای بالای برنامه و نگه‌داشتن فرماندهی فقط در دکمه‌های اصلی پایین‌تر
- تبدیل دکمه‌های اصلی به چیدمان ثابت دو ردیفه بدون اسکرول؛ دکمه انتخاب‌شده در جای خود روشن و قابل تشخیص می‌ماند
- افزودن کش هوشمند صفحه‌ای برای داشبورد، مشتریان، کالاها و گزارشات؛ جابه‌جایی یا حالت محرمانه باعث فراخوانی مجدد SQL نمی‌شود
- افزودن دکمه سه‌بعدی «تازه‌سازی دستی» با رنگ هماهنگ با تم و نمایش زمان آخرین بروزرسانی در داشبورد، مشتریان، کالاها، گزارشات و فرماندهی
- ثابت ماندن لیست مشتریان هنگام بازگشت از گردش حساب مشتری، بدون دریافت مجدد اطلاعات و اتلاف زمان
- افزودن تقویم زیبا و هماهنگ با تم برای تاریخ یادآوری مشتری به جای ورود دستی تاریخ؛ سال/ماه/روز پیش‌فرض از امروز انتخاب می‌شود
- بهبود خوانایی کارت‌های فرماندهی و آیتم‌های عملیاتی با پس‌زمینه و برچسب‌های پرکنتراست‌تر در تم آبی و سایر تم‌ها
- کوچک‌تر و رسپانسیوتر شدن میلو در صفحه دستیار تا چهره، دست‌ها و بدن کامل‌تر دیده شود
- مقاوم‌تر شدن گزارشات در برابر تفاوت ستون‌ها/جداول؛ هر گزارش مستقل بارگذاری می‌شود و خطاهای احتمالی در کارت عیب‌یابی هوشمند نمایش داده می‌شوند

### تغییرات مهم 3.19.0


- بازطراحی هدر بالای برنامه به ساختار دوبخشی: ردیف برند/لوگو جدا از ردیف ابزارها تا نام و لوگوی Meelano در بالا سمت راست ناقص یا مخفی نشود
- رنگ‌بندی جدید و پرکنتراست برای ابزارهای بالایی مثل جستجو، حالت محرمانه، انتخاب تم، فرماندهی، تنظیمات و خروج؛ مخصوصاً خواناتر در تم آبی روشن
- افزودن صفحه «فرماندهی هوشمند» با پیش‌بینی نقدینگی، تقویم مدیریتی، رادار کالا، مقایسه فروش/خرید و میانبرهای عملیاتی
- افزودن پیش‌بینی فشار نقدینگی بر اساس فروش، چک‌های دریافتی/پرداختی و بدهکاران اولویت‌دار
- افزودن تقویم مدیریتی روزانه برای مرور گزارش، تماس وصول، فاکتور معوق و بازفعال‌سازی مشتری خاموش
- افزودن رادار کالاهای طلایی/خطرناک برای تصمیم سریع موجودی، فروش و جلوگیری از خواب سرمایه
- افزودن امتیاز ریسک مشتری روی کارت مشتری و پروفایل ۳۶۰ همراه با پیشنهاد فروش نقدی/احتیاطی
- افزودن دکمه «پیام میلو» برای ساخت متن آماده وصول، فروش مجدد یا یادآوری چک/تعهد و ارسال از طریق Share/WhatsApp
- ارتقای دفترچه پیگیری مشتری به تاریخچه چندمرحله‌ای تماس، قول پرداخت و یادداشت محلی
- افزودن فرمان‌های صوتی ناوبری برای باز کردن بدهکارها، فرماندهی، گزارش‌ها، سلامت اتصال، تنظیمات و رادار کالا
- افزودن عیب‌یابی مرحله‌ای اتصال SQL بدون نمایش جزئیات محرمانه، در کنار تست latency
- افزودن خروجی CSV خلاصه فرماندهی روزانه
- ارتقای امنیت محلی برای PIN و کلیدهای AI با Android Keystore و حفظ سازگاری با داده‌های ذخیره‌شده قدیمی

### تغییرات مهم 3.18.0


- افزودن پیام مدیریتی «صبح بخیر مدیر» روی داشبورد با خلاصه فروش، چک، بدهکاران، مشتری خاموش و پیشنهاد میلو
- افزودن مرکز «کارهای امروز» با اولویت فوری/امروز/فروش/نقدینگی و دکمه انجام‌شده محلی
- افزودن ورود سریع امن با PIN و اثر انگشت پس از اولین ورود موفق Meelano، بدون نمایش جزئیات SQL
- افزودن ویجت صفحه اصلی Android برای خلاصه روزانه Meelano و ورود سریع به اپ
- افزودن تنظیمات یادآوری هوشمند برای چک، بدهکار، مشتری خاموش و گزارش روزانه؛ درخواست مجوز اعلان فقط هنگام فعال‌سازی
- افزودن پروفایل ۳۶۰ درجه مشتری و دفترچه پیگیری/قول پرداخت/یادآوری بعدی در صفحه گردش مشتری
- فعال‌تر شدن میلو با حالت صحبت‌کردن، خواندن گزارش روزانه و واکنش احساسی به ریسک/فروش/داده
- افزودن گزارش صوتی روزانه «میلو بخوان» با TTS فارسی دستگاه
- ارتقای PDF گزارش مدیریتی با سربرگ برند، کارت‌های سفید، رنگ سازمانی، امضا و نام فایل v3.18
- افزودن جستجوی هوشمند سراسری برای مشتری، کالا، چک و فاکتور از دکمه بالای برنامه
- افزودن حالت محرمانه برای ماسک‌کردن مبالغ حساس در UI هنگام نمایش در جمع
- افزودن جستجوی طبیعی داخل میلو برای عبارت‌هایی مثل بدهکارهای مهم، فروش امروز، ریسک امروز و چک‌های مهم
- افزودن صفحه سلامت اتصال با وضعیت SQL، latency، آخرین موفقیت/خطا و تست اتصال بدون افشای جزئیات فنی

- ارتقای Design System برنامه با کارت‌های Glass/Diamond، دکمه‌های براق، سایه نرم و هماهنگی بیشتر با تم پیش‌فرض آبی روشن
- ارتقای میلو با حالت‌های احساسی/فکری/نگران/هیجان‌زده، دهان متحرک هنگام فکر کردن و میانبرهای سریع مدیریتی
- افزودن جمع‌بندی مدیرعامل، امتیاز سلامت کسب‌وکار از ۱۰۰، مقایسه دوره‌ای، ۵ کار مهم امروز و خروجی متن/PDF/واتساپی برای گزارشات
- بهبود Empty State، خطای اتصال کاربرپسند بدون نمایش جزئیات فنی و لودینگ/اسکلت هماهنگ با تم
- لوکس‌تر شدن صفحه ورود با الگوی الماسی، پس‌زمینه آبی شیشه‌ای و دیالوگ خطای نرم‌تر
- ارتقای کارت مشتریان با برچسب هوشمند، آخرین خرید، اهمیت مشتری و تماس سریع
- فعال شدن کارت پکیج آیکن‌های سه‌بعدی Native/Glass هماهنگ با Meelano
- تحلیل و بازبینی سراسری پروژه و رفع موارد UX/کدنویسی کشف‌شده در نسخه نهایی
- تغییر تم پیش‌فرض برنامه به تم روشن «الماس آبی» برای نصب‌های جدید
- طبیعی‌تر شدن چهره پسته میلو با بافت پوسته، سایه‌پردازی، چشم‌های طبیعی‌تر، ابرو، بینی، گونه و لبخند واقع‌گرایانه‌تر
- جلوگیری از درخواست ناگهانی مجوز اعلان در شروع برنامه؛ مجوز فقط هنگام نیاز/تست اعلان درخواست می‌شود
- بهبود کش آفلاین، جایگاه بنر داده ذخیره‌شده، تنظیم فرمت اسکن QR/بارکد و آیکن امن اعلان اندروید
- تبدیل کاراکتر دستیار به «پسته میلو»؛ کاراکتر Native بدون پس‌زمینه، لوکس، خنده‌دار، تم‌پذیر و زنده با پلک‌زدن/نفس‌کشیدن آرام
- اضافه شدن هشدارهای امروز میلو در داشبورد و اعلان محلی برای مطالبات، چک‌ها و ریسک‌های فوری
- اضافه شدن کش آفلاین آخرین داشبورد و گزارشات برای زمان قطع اتصال SQL Server
- اضافه شدن تصمیم پیشنهادی زیر کارت‌های گزارشات برای تبدیل هر گزارش به اقدام مدیریتی
- اضافه شدن حالت جمع‌وجور، کاهش حرکت خودکار/دستی و Skeleton Loading برای تجربه گرافیکی بهتر و مصرف باتری کمتر
- اضافه شدن ابزارهای سخت‌افزاری: اسکن QR/بارکد از طریق اسکنر نصب‌شده، دسترسی سریع به بلوتوث/پرینتر، ارسال/چاپ خلاصه و تست یادآوری محلی
- اضافه شدن کارت راهنمای نصب امن و انتشار رسمی برای کاهش هشدارهای نصب اندروید در توزیع واقعی
- ثابت شدن لوگوی صفحه ورود مطابق آیکن برنامه و حذف انیمیشن آن طبق بازخورد
- کوچک‌تر و جمع‌وجورتر شدن میلو در پنجره نام کوچک و صفحه دستیار برای جاگیری بهتر در کادرها
- کاهش شدت حرکت میلو به نفس‌کشیدن و پلک‌زدن آرام، حذف تکان‌های زیاد و حذف پنل‌های ابری SQL/فروش/ریسک کنار دستیار
- تبدیل میلو از تصویر ثابت به موجود زنده Native با نقاشی برنامه‌ای، پلک‌زدن، نفس‌کشیدن، موج دست و اوربیت‌های داده آرام، بدون پنل/ابر جانبی مزاحم
- هماهنگ‌سازی لوگوی ورودی و لوگوی بالای برنامه با آیکن برنامه و تبدیل آن‌ها به نشان زنده/متحرک با حلقه‌های هوشمند و ادغام ظریف M/A
- بازدسته‌بندی کامل‌تر گزارشات به اتاق فرمان: درآمد و فروش، سودآوری/قیمت‌گذاری/کالا، وصول/مطالبات/چک، مشتری/وفاداری/بازار و عملیات روزانه
- اضافه شدن تابلوی سلامت مدیریت و اقدامات پیشنهادی امروز برای تبدیل گزارش‌ها به تصمیم‌های عملی
- افزودن بدهکاران اولویت‌دار، فاکتورهای معوق و مشتریان بدون خرید به گزارشات مدیریتی بدون چارت و بدون نمایش مبلغ بانک‌ها
- تغییر نام دستیار هوشمند به «میلو» در تمام صفحه‌های چت، صوت و تنظیمات مرتبط
- حذف کارت ورود دستیار از داشبورد؛ دستیار فقط از بخش مستقل «دستیار» در نوار اصلی باز می‌شود
- جایگزینی آواتار مربعی و تصویر ثابت دستیار با کاراکتر زنده Native، متحرک و تم‌محور در صفحه دستیار
- کوتاه‌سازی متن‌های راهنمای دستیار برای دیده‌شدن بهتر کاراکتر میلو
- بازطراحی پنجره گرفتن نام کوچک کاربر با کارت سه‌بعدی، پرتره میلو، گرادیان هماهنگ با تم و متن کوتاه‌تر
- بازطراحی گزارشات مدیریتی بدون چارت/گراف؛ بخش‌ها به کارت‌های کاربردی فروش، سود، وصول، مشتری، مطالبات، کالا و اسناد روزانه تبدیل شدند
- حذف نمایش مبلغ بخش بانک‌ها در گزارشات مدیریتی؛ فقط بانک‌های قابل پایش با تفکیک شعبه برای بانک‌های هم‌نام نمایش داده می‌شود
- ارتقای دوباره آیکن‌های فروش روزانه و خرید روزانه در داشبورد با طراحی Native سه‌بعدی، خواناتر و مرتبط‌تر با فروش/خرید
- بازطراحی آیکن برنامه با نشان سه‌بعدی Meelano که حرف A در فرم M ادغام و کمتر قابل تشخیص است
- جذاب‌تر شدن پس‌زمینه لاگین با گرادیان، هاله‌های تم‌محور و واترمارک برند

### امکانات پایه حفظ‌شده

- اپلیکیشن نصب‌شدنی Android با UI کاملاً Native
- بدون PWA، بدون HTML و بدون مرورگر داخلی
- اتصال مستقیم به SQL Server از داخل اپلیکیشن با JDBC
- عدم نمایش تنظیمات فنی اتصال در رابط کاربری
- ورود کاربر فقط با نام کاربری و رمز Meelano
- اعتبارسنجی روی جداول واقعی `visitors` و `sys_users`
- داشبورد Native غنی‌تر با کارت‌های فروش/خرید روز، چک‌های دریافتی/پرداختی، بدهکاران، فاکتورهای معوق، مشتریان بدون خرید و کالاهای فروخته‌شده روز
- داشبورد هوشمندتر با جدول فشرده آمار مشتریان/کالاها، بانک‌ها و هشدارهای پیگیری
- انتخاب تاریخ برای فروش و خرید روز، مشاهده روز قبل/بعد، منحنی همان تاریخ و ورود به فاکتورها، اسناد، اقلام و دریافتی/پرداختی‌ها
- تفکیک قابل کلیک چک‌های دریافتی و پرداختی با لیست جزئیات کامل هر وضعیت
- جابه‌جایی موجودی بانک‌ها زیر چک‌های پرداختی با نمایش آیکن بانک و مبالغ خوانا در همه تم‌ها
- بازطراحی تفکیک چک‌های دریافتی/پرداختی برای خوانایی بهتر مبلغ، تعداد و وضعیت
- تبدیل بدهکاران، تسویه‌های گذشته و مشتریان بدون خرید به کارت‌های تفکیک‌شده ۵تایی با رنگ و نمایش هماهنگ با تم
- انتخاب تم با کارت‌های رنگی کوتاه و حذف نمودارهای روند فروش/مشتریان برتر/مانده مشتریان از داشبورد
- آیکن اختصاصی برای بانک‌های رایج در جدول موجودی بانک‌ها و نمایش خواناتر نام/شناسه بانک داخل خود آیکن
- افزودن دسته «چک سفید / استفاده‌نشده» برای چک‌های پرداختی و جایگزینی عبارت‌های مبهم وضعیت با نام دسته چک
- انتقال متن اتصال بالای برنامه به نشانگر زنده اتصال کنار تنظیمات/تم و افزودن خروج سریع از حساب
- ارتقای کارت‌های مشتریان با چیدمان منظم‌تر، چیپ بدهکار/بستانکار/تسویه و متریک‌های هم‌اندازه
- تشخیص بانک‌های هم‌نام با کد شعبه برای جلوگیری از تداخل ردیف‌های موجودی بانک
- حذف دکمه رفرش بالای برنامه، نشانگر زنده اتصال تم‌محور، کارت‌های مشتری منظم‌تر و صفحه لاگین لوکس‌تر
- فشرده‌سازی هوشمند مبالغ خیلی بزرگ چک‌های پرداختی برای حفظ اندازه جدول
- KPI و نمایش‌های مدیریتی اختصاصی با رنگ‌بندی موضوعی و کارت‌های گرادیانی
- مشتریان با جستجو، فیلتر بدهکار/بستانکار/بدون خرید/پرخرید و کارت‌های متمایز رنگی
- گردش حساب کامل مشتری با ریز فاکتور فروش، چک دریافتی/پرداختی، وضعیت تسویه و فیلترهای کاربردی
- کالا و انبار با فیلتر موجود/کم‌موجودی/پرفروش/بدون گردش، کارت‌های محصول چندبخشی و پشتیبانی ستون تصویر محصول در صورت وجود
- نمایش Native برای فروش و چک‌ها از جدول‌های مجاز با برچسب‌های فارسی‌تر به‌جای کدهای خام
- گزارش‌های مدیریتی کاربردی بدون چارت/گراف در صفحه گزارشات
- پیام «عدم اتصال» و امکان تلاش مجدد در صورت قطع ارتباط
- حذف دکمه تنظیمات از نوار اصلی و انتقال تنظیمات به چرخ‌دنده بالای برنامه
- انتخاب تم از آیکن کنار چرخ‌دنده با ۶ تم لاکچری: سه تم دارک و سه تم روشن که رنگ دکمه‌ها، کارت‌ها، گزارش‌ها و عناصر تعاملی را هماهنگ تغییر می‌دهد
- اضافه شدن بخش عملیاتی «دستیار هوش مصنوعی Meelano» با چت فارسی، ورودی صوتی، خواندن پاسخ، شخصیت تم‌محور و پاسخ‌های کوتاه/دقیق
- تحلیل زنده دیتابیس برای فروش، خرید، مشتریان، بانک‌ها، چک‌ها، قیمت‌گذاری، پورسانت، پیشنهاد بازار و هشدار جلوگیری از زیان
- ذخیره و اعتبارسنجی جداگانه یا هم‌زمان کلیدهای ChatGPT، Gemini و Grok از بخش تنظیمات و انتخاب مدل پیش‌فرض
- پرسیدن نام کوچک کاربر در اولین ورود و خطاب کردن کاربر با همان نام در پاسخ‌های دستیار
- تفکیک زیباتر جستجوی مشتریان از فیلترهای هوشمند با پنل جداگانه پایین‌تر
- تغییر نام نمایشی برنامه روی صفحه گوشی به Meelano و ارتقای آیکن برنامه با ادغام خلاقانه حرف A در نشان فعلی
- ارتقای اسکرول‌بارهای عمودی و افقی با رنگ، گرادیان و مسیر متناسب با تم انتخابی کاربر
- اضافه شدن تم روشن لاکچری «الماس آبی» با رنگ آبی خوانا برای همه دکمه‌ها، کارت‌ها، گزارش‌ها و بخش‌های مرتبط
- اضافه شدن تم دارک لاکچری «نوآر شفق» با ترکیب نئونی آبی/بنفش و کنتراست بالا
- بازطراحی آیکن‌های فروش روزانه و خرید روزانه به نشان‌های سه‌بعدی Native و کاملاً تم‌محور برای تشخیص سریع‌تر بخش‌ها
- حذف هدر «داشبورد هوشمند» از بالای داشبورد و شروع مستقیم با داده‌های کاربردی
- ارتقای کارت دستیار هوشمند با المان‌های متحرک مرتبط با فروش، کالا، مشتری، چک و بانک
- بازطراحی لودینگ دریافت اطلاعات دیتابیس با نشان SQL سه‌بعدی، چیپ‌های متحرک و رنگ کاملاً هماهنگ با تم
- ارتقای دکمه‌های اصلی ناوبری به کارت‌های تم‌محور، سه‌بعدی‌تر و خواناتر
- حذف دکمه‌های اصلی «فروش» و «چک‌ها» از نوار اصلی و انتقال مسیرهای عملیاتی آن‌ها به داشبورد/گزارشات
- بازطراحی گزارشات مدیریتی به اتاق فرمان دسته‌بندی‌شده شامل فروش/سود، نقدینگی/چک/بانک، مشتریان/مطالبات، کالا/بازار و اسناد روزانه
- ارتقای دوباره آیکن برنامه با طراحی سه‌بعدی‌تر و ادغام ظریف حرف A در ساختار M
- تم‌های هماهنگ با برند Meelano و پشتیبانی RTL فارسی

## نکته امنیتی

این نسخه بنا به درخواست برای تست شخصی Direct SQL ساخته شده است. برای انتشار عمومی یا استفاده سازمانی، معماری امن‌تر زیر توصیه می‌شود:

```text
Android Native App → HTTPS API → SQL Server
```

## ساخت APK در Android Studio

1. Android Studio را نصب کنید.
2. پروژه `MEELANO-Android` را باز کنید.
3. SDK Platform 35 و Build Tools متناظر را نصب کنید.
4. Gradle Sync را انجام دهید.
5. برای فایل قابل نصب مستقیم:
   - `Build > Build Bundle(s) / APK(s) > Build APK(s)`
   - یا از ترمینال: `gradle :app:assembleRelease`

خروجی Release:

```text
app/build/outputs/apk/release/app-release.apk
```

نام فایل تحویلی این نسخه:

```text
MEELANO-Android-DirectSQL-v3.20.0.apk
```
