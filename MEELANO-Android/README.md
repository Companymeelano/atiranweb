# Meelano Android Direct SQL

این پروژه نسخه **اندروید واقعی و قابل نصب** برای Meelano است که برای تست شخصی با **اتصال مستقیم به SQL Server** آماده شده است.

## ویژگی‌های نسخه 3.4.0-direct-sql-luxury-themes

- اپلیکیشن نصب‌شدنی Android با UI کاملاً Native
- بدون PWA، بدون HTML و بدون مرورگر داخلی
- اتصال مستقیم به SQL Server از داخل اپلیکیشن با JDBC
- عدم نمایش تنظیمات فنی اتصال در رابط کاربری
- ورود کاربر فقط با نام کاربری و رمز Meelano
- اعتبارسنجی روی جداول واقعی `visitors` و `sys_users`
- داشبورد Native غنی‌تر با کارت‌های فروش/خرید روز، چک‌های دریافتی/پرداختی، بدهکاران، فاکتورهای معوق، مشتریان بدون خرید و کالاهای فروخته‌شده روز
- KPI و نمودارهای Line/Bar اختصاصی با رنگ‌بندی موضوعی و کارت‌های گرادیانی
- مشتریان با جستجو، فیلتر بدهکار/بستانکار/بدون خرید/پرخرید و کارت‌های متمایز رنگی
- گردش حساب کامل مشتری با ریز فاکتور فروش، چک دریافتی/پرداختی، وضعیت تسویه و فیلترهای کاربردی
- کالا و انبار با فیلتر موجود/کم‌موجودی/پرفروش/بدون گردش، کارت‌های محصول چندبخشی و پشتیبانی ستون تصویر محصول در صورت وجود
- نمایش Native برای فروش و چک‌ها از جدول‌های مجاز با برچسب‌های فارسی‌تر به‌جای کدهای خام
- گزارش‌های مدیریتی پایه با نمودارهای Native
- پیام «عدم اتصال» و امکان تلاش مجدد در صورت قطع ارتباط
- حذف دکمه تنظیمات از نوار اصلی و انتقال تنظیمات به چرخ‌دنده بالای برنامه
- انتخاب تم از آیکن کنار چرخ‌دنده با ۴ تم لاکچری: دو تم دارک و دو تم روشن که رنگ دکمه‌ها، کارت‌ها، چارت‌ها و نمودارها را هماهنگ تغییر می‌دهد
- تم‌های هماهنگ با برند Meelano و پشتیبانی RTL فارسی

## نکته امنیتی

این نسخه بنا به درخواست برای تست شخصی Direct SQL ساخته شده است. برای انتشار عمومی یا استفاده سازمانی، معماری امن‌تر زیر توصیه می‌شود:

```text
Android Native App → HTTPS API → SQL Server
```

## ساخت APK در Android Studio

1. Android Studio را نصب کنید.
2. پروژه `MEELANO-Android` را باز کنید.
3. SDK Platform 35 و Build Tools متناظر را نصب کنید.
4. Gradle Sync را انجام دهید.
5. برای فایل قابل نصب مستقیم:
   - `Build > Build Bundle(s) / APK(s) > Build APK(s)`
   - یا از ترمینال: `gradle :app:assembleRelease`

خروجی Release:

```text
app/build/outputs/apk/release/app-release.apk
```

نام فایل تحویلی این نسخه:

```text
MEELANO-Android-DirectSQL-v3.4.0.apk
```
